# Weather API Service

This service provides a clean interface for interacting with the **OpenWeatherMap API** using Axios and TypeScript.

## Project Purpose
The goal of this module is to abstract the complexity of API calls for location searching and weather retrieval. It allows the application to first find a city's coordinates and then fetch its current weather conditions.

## Features
* **Geocoding**: Search for city coordinates by name.
* **Weather Retrieval**: Get detailed weather data (temperature, wind, etc.) in metric units.
* **TypeScript Support**: Fully typed responses for better developer experience.
